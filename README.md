# 鲸鱼娘桌面宠物 (whale-girl-desktop)

一只可爱的鲸鱼娘桌宠，悬浮在你的 Windows 桌面上。基于 **Tauri 2 + React** 构建，独立运行，不依赖 DeepSeek Harness。

![鲸鱼娘](https://via.placeholder.com/1x1/transparent.png)

## 特性

- 🐳 **桌面悬浮**——透明无边框窗口，可自由拖动到屏幕任意位置
- 📌 **边缘吸附**——拖到靠近屏幕边缘时自动吸附（左/右/顶/底），拖到中间则悬停
- 🎯 **甩抛弹跳**——快速甩抛会在屏幕内物理弹跳（摩擦减速、撞边反弹 + 挤压动画）
- 🤚 **点击抚摸**——点击出现 petpet 抚摸动画 + 彩蛋台词气泡
- 💬 **气泡台词**——点击触发随机台词 / 快速连点 5/10 次触发彩蛋
- 🔊 **音效**——可爱合成音 / 鸭叫两种模式可切换
- ⏱ **信息面板**——显示当前时间、日期、CPU 使用率、内存占用
- 📦 **系统托盘**——最小化到托盘、单击托盘图标唤出
- 🔝 **置顶 / 开机自启**——右键菜单可切换
- 🎨 **完全复用原版挂件素材**——鲸鱼娘角色图、抚摸 gif、音效

## 构建与运行

需要 [Rust](https://rustup.rs/) 和 [Node.js](https://nodejs.org/)。

```bash
# 安装前端依赖
npm install

# 开发模式（自动热重载）
npm run tauri dev

# 构建正式版（release）
npm run tauri build
```

构建产物位于 `src-tauri/target/release/whale-girl-desktop.exe`。

> 首次构建需编译 Tauri 全部依赖，耗时较长（约 5-10 分钟）。

## 使用说明

| 操作 | 效果 |
|---|---|
| 左键拖动 | 移动桌宠 |
| 松手（靠近边缘） | 吸附到屏幕边缘 |
| 松手（屏幕中间） | 悬停在当前位置 |
| 快速甩抛 | 在屏幕内弹跳 |
| 左键点击 | 抚摸 + 台词气泡 |
| 右键 | 打开菜单（音效/气泡/信息面板/置顶/自启/托盘/退出） |

## 配置

设置通过右键菜单调整，自动保存到本地（localStorage），重启后保留。

## 技术栈

- **Tauri 2** — 无边框透明窗口、系统托盘、开机自启、系统资源读取
- **React 18** — 前端界面
- **sysinfo** — CPU / 内存数据
- **Vite** — 前端构建
